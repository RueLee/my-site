# Ruleon's Website
Welcome! You are now viewing an open-source project via GitHub on my website.

The site was developed starting from scratch and continued designing and testing until it was feasible to begin the launch. The purpose primarily showcases on the development of one's self and achievement, and couple quality of life tools.

Contributions and feedbacks are welcome!
# Web Architecture
<img width="921" height="522" alt="ruleonlee com-web-architecture drawio" src="https://github.com/user-attachments/assets/c09318f8-c957-40f4-a50a-9ea00646fa13" />

- [Next.js](https://nextjs.org/): Main framework for handling frontend
- [Tailwind](https://tailwindcss.com/): CSS utility plugin
- [ShadCN](https://ui.shadcn.com/): Additional UI components

Most of the codebases are written in Javascript. Services run on AWS alongside Cloudflare, where DNS is registered.
